## Data files

Default data live in `src/cess/data`. The [resource inventory](docs/RESOURCE_MANIFEST.json)
records the distributed file paths, sizes and SHA256 values.

| Resource | Files | Description |
| --- | ---: | --- |
| `csst_phot_tp/csst_phot.{nuv,u,g,r,i,z,y}.fits` | 7 | CSST seven-band photometric responses |
| `csst_sls_tp/*throughput*.fits` | 6 | GU/GV/GI zeroth- and first-order responses |
| `basic_file/updated_bkg.fits` | 1 | Fixed sky-background template |
| `basic_file/gems_cat.fits` | 1 | GEMS catalogue used for empirical morphology statistics |
| `basic_file/{widthlib,heightlib}_20x20x10x10.pkl` | 2 | Precomputed profile libraries generated by the CESS morphology renderer |
| `emulator_parameters.json` | 1 | Default configuration |

The throughput copies do not carry a unified upstream release number or date;
identify them by their file hashes. The filenames `GV_throughput_0th_no56.fits`
and `GV_throughput_1st_no1567.fits` are retained from the supplied responses.
Historical PSF and normalization assumptions in the precomputed profile libraries
are not fully documented; see the [model description](docs/SCIENCE_MODELS.md).

## Dependencies

NumPy, SciPy, Astropy, h5py, Specutils and optional packages are installed
separately and retain their respective licenses. CESS does not distribute pPXF
source. Its Gaussian smoothing helper is implemented independently and is not
the production `convolve_to_bins` operator.
