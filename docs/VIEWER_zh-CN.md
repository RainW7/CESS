# CESS HDF5 可视化浏览器

[English](VIEWER.md) | 简体中文

这个可选桌面工具可以打开 HDF5 文件，查看分组、数据集和属性，并绘制光谱或
星表变量。它适合在不另外编写分析脚本的情况下检查模拟输出。输入文件以只读
方式打开；图片和 CSV 表格作为独立文件导出。

本工具配合[用户指南](USER_GUIDE_zh-CN.md)和
[输出格式说明](OUTPUT_LAYOUT_zh-CN.md)使用。解释图表前先阅读数据集的定义、
单位和掩膜。图像能够显示不代表模拟已经完成科学定标。

## 1. 安装可选图形界面

使用 CESS 的 Python 3.12 环境。从下载或解压后的 CESS 源码根目录运行：

```bash
conda activate cess
cd /path/to/CESS
python -m pip install '.[viewer]'
python -m pip check
```

`viewer` extra 安装 Matplotlib；NumPy 和 h5py 已属于 CESS 核心依赖。界面使用
Tkinter 和 Matplotlib 的 TkAgg 后端。Tkinter 来自 Python/Tcl/Tk 安装，
**不是 pip 包**。Conda 用户应在同一个环境中安装或检查 Tk：

```bash
conda activate cess
conda install tk
python -m tkinter
```

最后一条命令应在图形桌面上打开一个小型 Tk 测试窗口，关闭它之后再继续。
如果 venv 使用的基础 Python 缺少 `_tkinter`，需要安装具有 Tk 支持的 Python
发行版并重新创建 venv；安装名字相似的 pip 包不能替代这个步骤。

浏览器是可选功能。仅进行批处理的 CESS 安装和 Gravity 作业不需要 Tk 或
浏览器窗口。交互查看时请使用具有图形桌面的计算机。核心环境说明见
[安装指南](INSTALL_zh-CN.md)。

## 2. 启动和切换语言

可以在任意工作目录运行，使用产物文件的绝对路径：

```bash
cess-viewer /path/to/results/product.hdf5
```

默认界面语言为英文。启动时选择中文：

```bash
cess-viewer /path/to/results/product.hdf5 --lang zh
```

不提供文件名时先打开空界面，再选择 **文件 → 打开 HDF5 文件**：

```bash
cess-viewer
```

等价的模块入口和源码目录兼容入口为：

```bash
python -m cess.viewer /path/to/results/product.hdf5 --lang en
python /path/to/CESS/cess_h5_viewer.py /path/to/results/product.hdf5 --lang en
cess-viewer --help
```

源码入口会优先加载当前目录的源码包，但仍需先准备好依赖环境。包含空格的路径应加引号。
**语言 / Language** 菜单可在运行时切换中英文；环境变量
`CESS_H5_VIEWER_LANG=en` 或 `CESS_H5_VIEWER_LANG=zh` 也可设置启动语言，
显式 `--lang` 参数优先。

## 3. 用小样本熟悉界面

在已激活的环境中，进入一个新的可写工作目录并使用全新的输出路径。
将 `/path/to/CESS` 替换为源码目录：

```bash
python /path/to/CESS/examples/make_toy_input.py toy.hdf5 --sources 4 --invalid-first
cess simulate -i toy.hdf5 -o toy_results --all-effects --seed 1214
cess-viewer toy_results/CSST_grism_toy_4.hdf5 --lang en
```

示例采用任意设定的光谱检查接口。第 0 行被故意设为无效：其 ID 和行映射保留，
但模拟光谱不应作为有效测量。切换到第 1–3 行可浏览其他示例光谱。
这个样本不能用于物理定标。

## 4. 四个工作页面

界面采用深色导航栏、浅色工作区和圆角主按钮。左侧可在四个页面间切换；
顶部显示当前文件和摘要，并按当前页面启用图片保存/数据导出。
未打开文件时显示开始页。窗口尺寸会适配屏幕；光谱控制区可滚动，
探索绘图的“筛选与显示选项”可展开/折叠，收起不会清空设置。
悬停文件名可看完整路径，悬停物理量可看实际数据字段。



| 页面 | 主要用途 |
| --- | --- |
| 数据浏览 | 浏览 HDF5 层级或按路径过滤；查看 shape、dtype、属性和表列定义；预览数据行并选择绘图变量 |
| 一维光谱 | 按产物行号或 ID 选源；显示可用的 GU/GV/GI 光谱、模型、误差、掩膜和 S/N；查看谱线标记并导出单源表格 |
| 探索绘图 | 选择数值变量绘制散点、折线、阶梯、直方图或 hexbin；可加入着色变量、Y 误差及数值表达式筛选 |
| 说明 | 查阅文件布局、物理量和界面操作 |

### 数据浏览

在左侧树中选择分组或数据集，信息面板显示文件保存的元数据。预览控件按页
展示数据，不会一次在表格中铺开整张大表。存在列定义元数据时优先显示列名；
结构化数组可展开数值字段。

对象信息、列清单和数据预览是三块独立的窗格：拖动它们之间的分隔条，
就能给较长的属性报告更多高度，或者把它压小、多看几行数据。
对象信息栏的 **A−** / **A+** 调整字号，**复制** 把整份报告拷到剪贴板；
**跳到行** 可直接翻到包含指定行的那一页，不必逐页点击；
「每页」可在 200 / 500 / 1000 / 2000 行之间切换。

点击表头会按该列对整份数据排序（行号仍显示原始行号），再点一次反向，
点第 0 列取消排序。「导出本页…」把当前看到的这些行写成 CSV，写入保护与
其它导出相同。

右键点击树节点可以「复制路径」「设为 X / 设为 Y / 设为颜色」（整个数据集或
当前选中的一列）以及「展开 / 折叠」；右键点击预览行可以到「一维光谱」页
查看该源，或复制整行。

选择一列并点击 **设为 X** 或 **设为 Y**，即可将其送到绘图页。
双列操作以第一个选中列为 X、第二个为 Y。这些操作只是选择已有数值，
不会重新计算物理量。

### 一维光谱

通过源行号控件、滑杆或箭头按钮更换当前行。行号从 0 开始，表示
**当前打开产物内部的行号**。对于子样本或分片，应结合 `input_row_indices`
及父产物映射找到原始星表行号。ID 是独立标识符，不一定等于行号。

选择所需波段与光谱物理量。查看含噪模拟观测使用 `flux_ujy_with_noise`，
`flux_ujy_model` 是对应的无噪模型；`flux_ujy`、电子计数及电子率等字段
有不同定义。其中 `source_electron_rate_pre_morph` 的单位为 electron s^-1 cm^-2。
比较误差前要确认它对应的物理量和单位。扣除背景后的负涨落
是有效数值；对称对数显示可以保留这些负值。

「加入对比」最多记住 4 个源行，用细线叠画在同一张图上，方便比较不同亮度
或红移的谱；双击列表项可移除。对比源使用与主曲线相同的物理量和波段。

「虚线对比」让对比曲线用虚线画，颜色相近时也能区分。「归一化」会把每条曲线
（含当前源）除以自身的中位流量或中位 1σ，便于比较不同亮度的谱形；所用因子会
写在标题和纵轴上。两个选项都不做平滑、平移或重采样，也不改动文件里的数值与
导出内容（本页导出的始终是未归一化的光谱）。归一化后个别发射线或边沿噪声
可达连续谱的上百倍，纵轴默认按 1–99% 分位截断（状态栏会提示），缩放、
改用对称对数纵轴即可看全。

三波段叠加视图把各波段曲线放在同一幅图中，并不重新进行流量定标、
对重叠像元作统计合并或填补波长空隙。检查重叠区域时仍需保留波段身份与掩膜。

参考峰和真值中心测量窗口的位置来自文件保存的参考信息。探测峰叠加显示的是
**已匹配的含噪谱峰**，同一个源可以包含多个峰，不会显示全部候选峰或误报峰。
已知参考位置的窗口测量不等于独立探测或可靠识别出的原子跃迁，峰标记也不代表
已经验证红移。区别见[科学模型说明](SCIENCE_MODELS_zh-CN.md)。

对于 `paired-wce` 产物，一维光谱页显示不带 WCE 的 base 分支。查看 WCE 分支时，
请在 X-Y 页显式选择 `*_wce` 字段；这两个分支使用同一次噪声实现。

历史 `_0th` 光谱数组是一级光谱网格上的诊断 proxy，不是生成的零级二维像，
也不是物理零级波段积分。现代产物的波段积分测量保存在 `zero_order` 下。

### 探索绘图

从数据集变量列表选择 X 和 Y。二维的“源 × 像素”光谱既可以按像素列查看
全体源，也可与对应波长向量配合，通过源行号控件查看某个源的光谱。
应核对结果的轴标签与长度：两个无关数组长度相同，并不保证它们对应同一批源。

数值筛选可使用 `x` 和 `y`，例如：

```text
(x > 22) & (y > 20)
```

每个条件应加括号，多个数组条件用 `&` / `|` 连接。筛选使用受限的数学表达式，
允许 `x`、`y` 和白名单内的 NumPy 函数，例如 `np.isfinite(x)`、`np.abs(y)`
或 `np.log10(x)`，不会执行任意 Python。所有绘图类型应用相同的有限值和
表达式筛选。着色变量或 Y 误差选择“不使用”选项即可清除。
“稳健范围”可能将离群点排除在显示坐标范围之外；
这是显示设置，不是新的质量标志或星表筛选。比较图像与完整样本时应查看状态提示。

图形工具栏提供缩放、平移与保存功能；子图设置还可直接输入边距与间距数值。

## 5. 保存图像和导出表格

在一维光谱或 探索绘图页使用 **文件 → 保存当前图**，可以生成 PNG、PDF
或 SVG。保存影响显示的图形，不修改 HDF5。

一维光谱页将当前源的选中波段导出为 CSV，包含波段标签、波长、显示的光谱
物理量及相关列。使用前检查列标题，并保留波段身份。它是便于检查的表格，
**不能完整替代 CESS 产物**：不会保留全部 provenance、波长边界、协方差、
标志及可选测量。科研测量或可复现产物交换仍应使用原始 HDF5 和 CESS reader。

X-Y 页导出**最近一次绘图的数据快照**，应用当时的有限值和表达式筛选。
散点、折线和阶梯图选择了着色或 Y 误差时，CSV 除 X/Y 外还包含这些列；一维直方图只导出 X。
hexbin 导出的是输入点，不是计算后的分箱计数。“稳健范围”和对数轴仅改变
显示方式，不会从导出数据中删除数值。数值保留完整精度，并按 CSV 规则转义。
后续使用前应检查列标题。

请导出到独立位置并保留原始 HDF5。CSV 导出拒绝使用 HDF5 文件后缀，且会保护
当前打开的输入文件，包括通过符号链接或硬链接指向同一文件的路径。

macOS 快捷键包括 Cmd-O 打开、Cmd-S 保存当前图、Cmd-E 导出，以及光谱页
的左右方向键切换源。也可以用菜单完成相同操作。

## 6. 文件兼容性和大文件行为

可以浏览 CESS schema 3.0 和兼容的旧版波段分组。通用结构树也可用于检查
BayeSED 形状的输入及其他 HDF5 数据集。查看原始输入时，在 X-Y 页选择
实际的波长向量与光谱矩阵，并核对单位：浏览器不会替模板施加红移、卷积、
仪器响应或噪声。

并不是所有 HDF5 都包含 CESS 光谱。仅有发射线后处理的产物可能保存星表和
谱线表而不复制父产物的光谱数组。缺失或禁用的测量不能由浏览器重建，
查看光谱时需要打开父模拟产物。不同历史版本的布局与字段也可能不同；
历史三维测光参数表不属于标准表格绘图接口的支持范围。

单源光谱浏览读取所选行，结构预览采用分页；部分操作仍会读取整列、全部 ID
或谱线表。因此，星表绘图、统计和反复选择会占用内存，大文件可能使界面
短暂停顿。浏览器是桌面检查工具，不是分布式或 out-of-core 星表分析引擎。
可先查看少量源行，在内存有限的机器上避免不必要的全列绘图。
更换行号不会重新运行模拟。

## 7. 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 找不到 `cess-viewer` | 激活安装 CESS 的环境；尝试 `python -m cess.viewer --help`，并检查 `python -m pip show cess` |
| 缺少 Matplotlib | 在当前 CESS 环境安装 `viewer` extra |
| 缺少 `_tkinter` 或 Tk 后端无法启动 | 用 `python -m tkinter` 检查当前环境的 Tk；需要图形桌面 |
| 服务器提示 no display / cannot connect to display | 在有图形桌面的工作站查看文件；Gravity 模拟脚本不依赖 GUI |
| 中文显示为方框 | 安装或选择支持中文的字体，或切换到英文界面 |
| 光谱页为空 | 检查所选行的质量标志，以及文件是否包含光谱；EL-only 产物和原始输入可能需要其他页签或父产物 |
| 图中数值看起来不一致 | 检查单位、当前物理量、源行映射、掩膜、启用模型和坐标轴选择，不能仅凭文件名解释 |
| 大星表操作暂停 | 避免全列绘图/统计，优先使用单源控件，或使用独立分析脚本 |

模拟命令见 [Bash 命令手册](COMMANDS_zh-CN.md)，产物解释见
[输出格式说明](OUTPUT_LAYOUT_zh-CN.md)。
