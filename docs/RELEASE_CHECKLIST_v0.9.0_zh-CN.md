[English](RELEASE_CHECKLIST_v0.9.0.md) | [简体中文](RELEASE_CHECKLIST_v0.9.0_zh-CN.md)

## 已确定的发布决定

- 自有源码和文档采用 [MIT](../LICENSE)，版权持有人以 CESS contributors 标识。
- 维护者同意当前 throughput、背景和形态资源随包分发；见 [资源说明](../RESOURCE_NOTICE_zh-CN.md)与[文件清单](RESOURCE_MANIFEST.json)。
- throughput 的“最新”是维护者对当前提供副本的说明；记录文件 SHA，不补造官方 release 日期或数据许可证。
- 当前生产流程不调用旧 `varsmooth`；其沿用的上游实现已移除，同名兼容方法采用独立 Gaussian 积分，原研究快照不随源码包分发。
- 当前不发布真实 BayeSED 星表、科学输出、私人路径、环境目录或开发 checkpoint。

发布源码版本已收束为0.9.0。用户已完成指定整文件及六输入目录的运行，随后完成并发增强的相关检查。准确0.9.0源码和构件的最终验证摘要单独保存，不以旧开发版记录代替。不能跨源码身份直接续用旧manifest。

## 用户验收

完整运行指定 HDF5，核对源数/ID/行映射、正常源的一维结果、无效行标记及结果可读性。
用户反馈通过后，维护者和发布协作者收束本版；若发现新问题，先修复并更新相关证据。
已收到用户整文件与整目录运行完成的反馈。文件级并发原已由 `-j` 支持，当前增加清楚的进程/线程提示与目录服务器封装。小样本并发验收不等于整目录或Gravity性能认证。

## 最终冻结与发布

本地0.9.0干净源码目录的完整回归已通过：1626通过、1项依赖私有真实产物的可选检查跳过。公开Bash示例已做语法检查，并以微型输入实际验证安装包的整文件、目录并发、续跑、分片合并、布局、后处理和绘图；未据此声称全新依赖环境、Gravity调度或仪器科学定标已获验收。详细过程记录留本地，构件旁提供简短验证摘要与SHA。

1. 核对冻结源码为 `0.9.0`，版本声明、变更说明、Gravity预期身份和用户文档一致。
2. 重建 wheel/sdist，确认 MIT、资源说明和文件清单进入相应构件；核对必要兼容入口及测试闭包。
3. 在声明环境验收完整回归和安装后的公开示例。Conda安装说明不等于已完成全新Conda环境安装验收，测试结果绑定实际环境与源码。
4. 核对逐文件发布清单及 Git diff，排除私有/历史研究内容；根据用户发布授权提交、推送并创建版本标签与GitHub release。
5. 保留构件 SHA、发布源码身份及验证摘要，便于复现。

GitHub发布、服务器安装和qsub提交尚未因本文件自动执行。
Gravity全量重算、仪器科学定标和CESS+开发分别开展，不要求把它们全部完成后才发布一维v0.9.0。
