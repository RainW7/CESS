# CESS v0.9.0

[English](RELEASE_NOTES_v0.9.0.md) | [简体中文](RELEASE_NOTES_v0.9.0_zh-CN.md)

CESS v0.9.0保留BayeSED HDF5输入接口及主要一维功能，重构为Python3.12软件包，生成CSST GU/GV/GI模拟光谱、误差、掩膜、测光和发射线诊断。

主要变化：

- 按功能组织源码，合并重复流程，提供统一 `cess` 命令。
- 改进响应/光子积分、噪声与波长重采样误差传播；保留负的背景扣除后噪声涨落，保存相邻协方差。
- 科学 revision `20261027-D5` 依据 arXiv:2511.06917v2 表1更新随包 GU/GV/GI 波长范围与中央分辨本领，并显式声明一维响应、模板、采样和波长窗口约定，见[仪器模型](INSTRUMENT_MODEL_251106917_zh-CN.md)。
- 保留异常输入的ID和原始行，以质量位标记并跳过模拟，不修改上游文件。
- 默认每输入一份完整HDF5；目录、glob和显式源区间均可运行。`-j` 控制文件/分片进程，数值库线程请求默认1。
- 新增 `cess merge`，按行顺序流式合并科学字段并重映射发射线源引用，生成自包含文件。
- 新入口默认分组式schema3.0，保留legacy2.5及统一reader。输出记录配置、输入/源码/资源身份和随机流；manifest严格续跑且拒绝覆盖。
- 提供可选MGE strip提取、公开toy示例、中文安装/命令/用户指南及Gravity目录任务模板。
- 自有源码与文档采用MIT；随包资源的范围、SHA和来源边界单独说明。

- 纳入可选中英文[HDF5桌面浏览器](VIEWER_zh-CN.md)，用于只读结构/光谱浏览、筛选绘图及CSV/图片导出（`cess-viewer`、`viewer` extra）。

## 安装和迁移

使用Python >=3.12,<3.13的新环境，按[安装指南](INSTALL_zh-CN.md)从本源码或准确构件安装。不要沿用旧Python3.7环境的依赖清单，也不要因软件名相同就直接从PyPI安装不明来源的 `cess`。

旧BayeSED输入无需预转换，仍须满足命名字段/单位契约。新版科学算子修正意味着不能要求与历史v0.8.5数值完全相同；变化应结合字段语义和模型约定解释。可选2.5输出与默认3.0布局不同，建议改用reader和字段名，避免固定列号。

开发版或旧版manifest绑定其原源码/资源身份，不能跨软件版本或科学revision续跑。软件版本仍为 `0.9.0`，当前科学revision为 `20261027-D5`，与此前D4产品的科学设置不同。已有科学产品保持原始生成身份，不需要为改变版本标签而重写；D5重新计算使用新的输出目录和manifest。默认1worker，批量并发要显式指定 `-j N`，同时确保CPU与内存足够。

## 使用与已知边界

[快速开始](QUICKSTART_zh-CN.md) · [Bash命令](COMMANDS_zh-CN.md) · [用户指南](USER_GUIDE_zh-CN.md)

随包默认配置采用 constant-FWHM Gaussian 仪器响应和每参考FWHM四像元采样，均为显式的一维近似；参考文献的中央R不确定完整的波长依赖LSF。输入库单独采用 Gaussian R=300 近似；GU中模板已宽于目标时，`preserve` 保留原宽度，不进行锐化，并警告目标未达到。分析窗口根据实际输入的波长中心确定。假设及保留的观测约定见[仪器模型](INSTRUMENT_MODEL_251106917_zh-CN.md)。

历史profile属性和实际仪器PSF/背景/灵敏度仍需针对科研用途核查。窗口线S/N不等于完备度或独立检出显著度；零级积分测光不等于CCD零级图像。模型定义与限制见[科学说明](SCIENCE_MODELS_zh-CN.md)。
